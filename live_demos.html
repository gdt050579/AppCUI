Live demos

The examples below are the AppCUI examples from the Examples folder, compiled to WebAssembly and running in your browser through the browser frontend (see Frontends (terminals)). Each one is the same C++ code that runs in the Windows console, in a terminal or in an SDL window - only the frontend differs. Click inside a demo to give it the keyboard focus; close its last window to end it.
