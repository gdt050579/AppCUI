AppCUI::Application

namespace Application

Application lifetime: initialization (Init, InitializationData), the event loop (Run), desktop windows (AddWindow, ArrangeWindows), menus, themes, settings (<executable>.ini) and custom frontends.

Classes

  • CommandBar

  • Config

  • CustomFrontendInterface - A frontend implemented by the application instead of a real terminal (headless / remote / recording screens).

  • FrontendEvent - An input event produced by a custom frontend (see CustomFrontendInterface::WaitForEvent).

  • InitializationData - Every parameter of Application::Init.

Enumerations

enum class AppCUI::Application::InitializationFlags : uint32

Options of Application::Init (they can be combined with |).

Values:

enumerator None = 0
enumerator CommandBar = 0x0001

a command bar (shortcut keys) is shown on the last line

enumerator Menu = 0x0002

a menu bar is shown on the first line (see Application::AddMenu)

enumerator Maximized = 0x0004

the terminal window is maximized (frontend dependent)

enumerator Fullscreen = 0x0008

the terminal window is full screen (frontend dependent)

enumerator FixedSize = 0x0010

the terminal window can not be resized (frontend dependent)

enumerator LoadSettingsFile = 0x0020

loads <executable>.ini; its [AppCUI] section configures the application

enumerator AutoHotKeyForWindow = 0x0040

every new window receives a free Alt+1 .. Alt+9 hot key

enumerator EnableFPSMode = 0x0080

Control::OnFrameUpdate is called ~30 times per second.

enumerator SingleWindowApp = 0x0100

single application mode: start with Application::RunSingleApp

enumerator DisableAutoCloseDesktop = 0x0200

the application keeps running after its last window was closed
