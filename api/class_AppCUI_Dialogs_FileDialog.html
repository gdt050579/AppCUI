FileDialog

AppCUI::Dialogs::FileDialog (class)

class FileDialog

Modal open / save file dialogs.

extensionsFilter restricts the files that are shown. If it is empty, “All files” is used. Format: <Name>:ext|<Name>:ext|... or <Name>:ext1,ext2,ext3|<Name>:ext|.... For example "Text Files:txt|Images:jpg,jpeg,png|Documents:pdf,doc,docx,xlsx,xls,ppt,pptx" shows the “Text Files” filter (only .txt files); if the user selects “Images”, .jpg, .jpeg and .png files are shown.
