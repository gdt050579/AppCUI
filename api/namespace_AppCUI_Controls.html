AppCUI::Controls

namespace Controls

Every visual element: windows, buttons, text fields, lists, trees, grids, splitters, tabs, menus and the base Control class.

Controls are created through the AppCUI::Controls::Factory classes and positioned with layout strings.

Namespaces

  • AppCUI::Controls::Factory - Creation helpers: Factory::<Control>::Create(parent, …, layout, …) creates a control and adds it to its parent (returning a non-owning Reference) or returns an owning Pointer when no parent is given.

  • AppCUI::Controls::Handlers - Event handlers that can be attached to a control (control->Handlers()->OnXXX = …) instead of deriving a new control class: either a pointer to an object that implements the matching On…Interface or a plain function (a lambda without captures).
